# Hashtag setleri

Video başına **4-6 etiket**. 20 etiket atmak erişimi artırmaz, spam sinyali verir.
Her videoda seti aynen kopyalama — 2-3 tanesini değiştir.

## Set A — oyun keşfi (varsayılan)
```
#mobilegame #indiegame #hypercasual #onetap #gamedev
```

## Set B — rage/fail videoları
```
#gamingfail #ragequit #mobilegaming #tryagain #skillissue
```

## Set C — tatmin edici / ASMR
```
#satisfying #oddlysatisfying #minimalgame #asmrgaming #relaxing
```

## Set D — geliştirici perde arkası
```
#indiedev #solodev #gamedevelopment #buildinpublic #madewithcode
```

## Set E — Türkçe hesap kullanırsan
```
#mobiloyun #oyungeliştirici #yerlioyun #refleksoyunu
```

> Hedef kitle global olduğu için **birincil dil İngilizce**. Türkçe etiketleri yalnızca
> ayrı bir Türkçe hesap açarsan kullan; ikisini aynı videoda karıştırma.
